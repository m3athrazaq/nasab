# نَسَب

شجرة عائلتك على هاتفك: الآباء والأجداد والأعمام والأخوال وكل الفروع، بأسمائهم وكناهم وتواريخهم بالهجري والميلادي، تُعرض شجرةً تكبّرها بإصبعك، وتخرج لوحةً تُطبع وتُهدى، وكتاباً للعائلة، وشهادة نسب، وملفاً تفاعلياً يُرسل للأقارب.

## ما يقدّمه

**البداية في ثوانٍ**
- اكتب اسمك الكامل مرة واحدة («خالد راشد محمد عبدالله الراشد») فيُضاف أبوك وأجدادك مرتبطين، ويُحفظ اسم العائلة للجد الأعلى ويرثه الأبناء.
- أضف الأبناء أو الإخوة دفعة واحدة، اسماً في كل سطر، والجنس يُعرف من الاسم (وتغيّره بلمسة).
- أكثر من زوجة، وأبناء كل أم تحتها، وزواج الأقارب، والطلاق. وتراجع عن أي تعديل بلمسة، وادمج شخصين كُتبا مرتين.

**الشجرة**
- أربعة أشكال: شجرة من الجد الأعلى إلى الأحفاد، وقائمة أفقية، وشجرة حقيقية بجذع وأغصان، ومروحة الأجداد (آباؤك وأمهاتك جيلاً بعد جيل).
- الرجال أختام مربعة والنساء دوائر، والمتوفى بختم مفرّغ، ولكل فرع لونه، و«الخيط الأحمر» يصلك بجدك الأعلى. أشرطة للأجيال، وصور الأفراد، وطيّ الفروع، وإظهار ذرية البنات أو إخفاؤها.
- بحث بالاسم أو بالاسم واسم الأب («فهد محمد»)، ولا يهم ة أو ه ولا الهمزات.

**التفاصيل**
- الكنية («أبو فيصل» يقترحها من أكبر أبنائه) واللقب والشهرة، والميلاد والوفاة بالهجري أو الميلادي مع التحويل الدقيق بتقويم أم القرى، أو سنة تقريبية فقط، والمكان والمهنة والتعليم والإقامة والهاتف والسيرة والصورة.
- الاسم الكامل بـ«بن» و«بنت» أو بدونها، و«رحمه الله» بعد أسماء المتوفين، وأرقام عربية أو لاتينية.

**صلة القرابة**
- اختر أي شخصين: «ابن عم والدك»، «جدك لأمك»، «أخوك لأبيك»، «زوجة أخيك»… مع درجة القرابة والطريق بينهما في الشجرة، وكل الصلات إن تزوّج الأقارب. وفي كل القوائم يظهر ما يكونه كل فرد لك.

**أرقام العائلة**
- الأفراد والأحياء والأجيال، والأسماء الأكثر تكراراً، وأكبر الأسر، ومتوسط الأعمار وأطولها، وزواج الأقارب، والأماكن، والعقود، ومدى اكتمال البيانات.
- المناسبات القادمة (ذكرى الميلاد والوفاة والزواج، كلٌّ بتقويمه)، و«في مثل هذا اليوم».

**اطبعها وأهدها**
- **لوحة الشجرة**: ملف PDF بأي مقاس حتى A0 (أو مقاس يتسع للشجرة كلها)، أو صورة PNG أو SVG، بخمسة مظاهر: سدو، ونخيل، ومخطوطة، وعصري، وليلي. الأسماء خطوط متجهة حادة عند أي تكبير، وتُطبع كما تراها.
- **كتاب العائلة**: ملف PDF بمقاس A4: غلاف، وتمهيد بالمحتويات، والشجرة، وكل فرع في صفحته، وسِيَر الأفراد بتواريخهم بالتقويمين، وفهرس للأسماء بأرقام الصفحات.
- **شهادة نسب**: صفحة لشخص واحد بنسبه كاملاً واسم أمه وعمود آبائه حتى الجد الأعلى، بالبسملة إن أردت.

**شاركها واحفظها**
- **شجرة تفاعلية للأقارب**: ملف HTML واحد يُرسل في واتساب ويفتح في أي متصفح دون تطبيق ودون إنترنت، فيه البحث والتكبير والتفاصيل. وتُخفى تواريخ الأحياء إن أردت، ولا تُكتب فيه الهواتف ولا البريد أبداً.
- **GEDCOM** للبرامج الأخرى (MyHeritage وAncestry وFamilySearch وGramps)، ويُستورد منها أيضاً.
- **نسخة إكسل احتياطية** بالصور، تحفظها في درايف أو أي مكان، وتسترجعها دمجاً مع بياناتك أو استبدالاً لها. ويمكنك كتابة الشجرة كلها في إكسل (رقم لكل شخص ورقما أبيه وأمه) ثم استرجاعها. وعلى أندرويد تفتح الملف من درايف أو واتساب مباشرة: «فتح باستخدام ← نَسَب».

**الخصوصية**
- لا حساب ولا خادم ولا إعلانات ولا تتبّع، وقفل برمز إن أردت. البيانات على هاتفك فقط، وتطبيق أندرويد لا يملك صلاحية الإنترنت أصلاً. التفاصيل في [SECURITY.md](SECURITY.md).

## محتوى المستودع

- `index.html` و`app.js` و`sw.js` و`fonts/` و`vendor/`: التطبيق الجاهز كما يُنشر على GitHub Pages ويوضع داخل تطبيق أندرويد.
- `src/`: الكود المصدري (Preact): `core/` البيانات والتواريخ والأسماء والقرابة، و`chart/` رسم الشجرة (الشاشة والـPDF والصور من رسم واحد)، و`export/` الطباعة والملفات، و`ui/` الشاشات. بعد أي تعديل شغّل `npm ci --ignore-scripts` ثم `node tools/build.mjs`.
- `tests/`: اختبار المنطق (`node tests/core.test.mjs`) واختبار المتصفح (`tests/web.test.cjs`).
- `native/`: يحوّل الملفات نفسها إلى تطبيق أندرويد (Capacitor)، ومعه إضافات صغيرة: قراءة ملف الإكسل أو GEDCOM المختار أو المفتوح بالتطبيق، وطباعة ملفات PDF، ومنع فتح أي عنوان خارجي.
- `native/signing/`: مفتاح توقيع نسخة أندرويد، مشفّراً. يُفتح على GitHub فقط بالسر `SIGNING_PASSPHRASE`. لا تحذفه، فالتحديثات لا تُثبَّت إلا بالمفتاح نفسه.
- `.github/workflows/`: كل تعديل يُرفع يُختبر في متصفح حقيقي، ويُبنى منه ملف APK موقّع يُنشر في Releases.
